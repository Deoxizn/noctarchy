Noctarchy

Night Rule — Niri + Noctalia on Omarchy

Install GitHub

What is it?

A shell replacement for Omarchy. It swaps Hyprland and omarchy-shell for Niri (scrollable-tiling Wayland compositor) and Noctalia (native C++23 desktop shell). Different paradigm, lighter footprint, same theme system.

This is not a theme or a plugin — it is a full shell swap. Expect stock Omarchy to not behave stock after installing. Read before installing.

Install

git clone https://github.com/deoxizn/noctarchy.git ~/.local/opt/noctarchy
cd ~/.local/opt/noctarchy
./install.sh

Add -y to skip prompts, or --dry-run to preview without touching anything.

Compatibility

omarchy-shell (bar, notifs, OSD) Removed Noctalia provides all three

Hyprland config (Lua) Removed Niri KDL config replaces it
